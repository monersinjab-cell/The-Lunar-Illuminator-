# AI Knowledge Charter Tests

## Run

From the repository root:

    python3 -m unittest discover -s milyar/tests -v

These tests check the presence and completeness of important policy statements
in `milyar/AI_KNOWLEDGE_CHARTER.md`.

They do not prove that an AI model follows the charter, that every claim is
true, or that Quranic text has been independently verified against a source.
Model behavior requires separate tests and controls.

# بروتوكول العقل المركزي لمنير

## الهدف
تنظيم مصادر المعرفة والملفات والاتصالات المصرح بها
ضمن مشروع قمرا منيرا بإذن ربه.

## قواعد العمل
1. القرآن الكريم نص مستقل لا تعدله أدوات البحث.
2. كل استنتاج أو فرضية يحمل تصنيفا واضحا.
3. كل اتصال خارجي يتطلب واجهة موثقة وصلاحية صحيحة.
4. لا تُحفظ مفاتيح API أو كلمات المرور داخل المستودع.
5. لا يُدّعى ربط نموذج قبل نجاح اختبار الاتصال.
6. لا يُسمح بالوصول إلى أجهزة أو حسابات دون إذن.
7. تسجل نتائج الفحوص مع تاريخها، دون ادعاء حماية مطلقة.
8. تبقى القرارات الحساسة تحت مراجعة بشرية.

## حالة التنفيذ
تم إعداد ملفات التهيئة فقط.
لم يتم إثبات اتصال أي نموذج خارجي بهذا الملف.

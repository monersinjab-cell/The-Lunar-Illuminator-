# نموذج الأثير — مشروع القمر المنير

الحالة: فرضية غير مثبتة.

## الهدف
محاكاة تعليمية لموجة رياضية وتسجيل النتائج في ملف JSON.

## حدود النموذج
- المحاكاة الرياضية لا تثبت وجود الأثير المادي.
- النتائج ليست تجربة فيزيائية على أجهزة حقيقية.
- لا تُنسب نتائج النموذج إلى القرآن.
- يُحفظ النص القرآني دون تعديل أو إضافة تفسير آلي.
- أي فرضية فيزيائية تحتاج إلى أدلة قابلة للتحقق وتجارب مستقلة قابلة للتكرار.

## التشغيل
```bash
python research/physics/ether_model/ether_model.py
```

ينشئ البرنامج تقرير simulation_report.json داخل مجلد النموذج.
